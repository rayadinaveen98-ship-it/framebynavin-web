# FrameByNavin Web — Design Direction V1

Status: LOCKED
Date: 2026-09-19

## Decision

The V1 visual direction is **Cinematic Control Room** (Concept B), with one structural idea retained from Concept C: a future-facing project grid for **Cinema / Stories / Apps / Games**.

This is the master visual direction for V1 implementation.

## Core identity

The website should feel like a premium creative control room: cinematic, technical, intentional and alive, but never like editing software or a sci-fi dashboard.

The experience should communicate that FrameByNavin currently centers on cinema analysis while the broader creator system can expand into stories, apps, games and original projects.

## Visual principles

1. Near-black base with restrained warm-white text.
2. FrameByNavin recording red is the primary accent and must stay sparse.
3. Technical metadata is used as atmosphere: frame numbers, REC language, aspect ratio, FPS, status labels and section indexing.
4. Large typography carries the emotional weight; UI chrome stays compact.
5. Borders and grids provide structure instead of cards with heavy shadows.
6. Motion should feel like an edit suite: reveals, wipes, subtle monitor activation, timeline-like progress and measured hover states.
7. The interface must remain readable and premium on mobile; desktop-only gimmicks never block content.

## Locked hero direction

- Brand: FRAMEBYNAVIN + red recording dot.
- Status language: creator system / online / India.
- Left rail with section/index metadata.
- Large headline built around frame/story/world language.
- Primary CTA: View Work.
- Secondary CTA: Start a Project.
- Right-side monitor module for featured media/visual preview.
- Proof ticker directly beneath the hero.

## Locked project system

The homepage includes four project cards:

- Cinema — FrameByNavin, analysis, scene breakdowns and cinematic moments.
- Stories — original narratives, writing experiments and narrative worlds.
- Apps — digital products and creator/product experiments.
- Games — story-driven interactive projects and game development work.

Cinema remains the strongest and most developed category in V1. The other categories may use 'in development' or 'coming soon' states until public work exists.

## Commercial rule

The site can present promotions, brand partnerships and entertainment collaborations, but paid promotional work must remain clearly distinct from independent editorial analysis/reviews.

## V1 homepage flow

1. Global navigation
2. Cinematic Control Room hero
3. Social proof ticker
4. Projects: Cinema / Stories / Apps / Games
5. Selected Work / Case Studies
6. Services / Work With Me
7. Media Kit CTA
8. About / creator philosophy
9. Collaboration CTA / enquiry entry point
10. Footer

## Out of scope for visual direction

- Generic creator-link-page layouts
- Heavy glassmorphism
- Excessive neon/glow
- Fake film scratches everywhere
- Decorative clapperboards/film reels
- Dense dashboard widgets with no meaning
- Overuse of red
